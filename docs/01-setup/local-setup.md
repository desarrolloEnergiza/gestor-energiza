# Setup Local

El objetivo del setup local es permitir que cualquier desarrollador
pueda ejecutar el proyecto en su entorno sin dependencia de configuraciones
personales.

Cada proyecto derivado debe documentar:
- pasos de instalación,
- configuración de entorno,
- datos iniciales necesarios,
- verificación de funcionamiento.

Proyecto Génesis no impone un método específico
(Docker, Laravel Sail, instalación manual).
