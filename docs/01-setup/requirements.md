# Requisitos del Proyecto

Estos requisitos representan una base mínima esperada.
Cada proyecto derivado puede extenderlos o modificarlos.

## Requisitos generales
- PHP (versión definida por el proyecto derivado)
- Composer
- Node.js y NPM/Yarn
- Motor de base de datos relacional

## Requisitos de desarrollo
- Entorno local reproducible
- Variables de entorno documentadas
- Acceso a logs locales

Las versiones exactas deben definirse en el proyecto derivado.
