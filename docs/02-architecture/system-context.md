# Contexto del Sistema

Los proyectos derivados de Génesis suelen consistir en:

- una aplicación web Laravel,
- una base de datos relacional,
- servicios externos (correo, almacenamiento, APIs),
- usuarios con distintos roles.

El sistema se concibe como un monolito modular,
donde las responsabilidades están claramente separadas
a nivel de dominio y documentación.
