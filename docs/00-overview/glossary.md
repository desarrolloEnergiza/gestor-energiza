# Glosario

**Proyecto Génesis**  
Repositorio base que define estándares de documentación y creación de proyectos.

**Proyecto derivado**  
Proyecto que nace a partir de Proyecto Génesis y contiene lógica de negocio.

**ADR (Architecture Decision Record)**  
Documento que registra una decisión técnica relevante, su contexto y consecuencias.

**Preset de proyecto**  
Conjunto de decisiones iniciales que definen el stack y alcance técnico del proyecto.

**Feature**  
Funcionalidad concreta documentada como unidad independiente.
