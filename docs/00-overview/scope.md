# Alcance

## Incluye
- Estructura base de documentación.
- Convenciones de desarrollo.
- Modelos para decisiones técnicas (ADR).
- Guías de setup, seguridad y operación.
- Base conceptual para proyectos Laravel.

## No incluye
- Lógica de negocio específica.
- Decisiones cerradas de stack.
- Infraestructura productiva definida.
- Configuración final de CI/CD.

Estas decisiones deben ser tomadas y documentadas
en cada proyecto derivado.
